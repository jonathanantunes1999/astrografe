Política de privacidade

Explicamos que dados pessoais recolhemos através deste site, para que os usamos e que direitos tem sobre eles.

Rever antes de publicar: NIF da empresa, prazo de conservação dos dados e confirmação de que o serviço de envio de formulários cumpre as garantias exigidas.

1. Quem é o responsável

O responsável pelo tratamento dos dados é a Astrografe — Artes Gráficas, Lda., com sede na Rua Duarte Tarré, 45, 2670-505 Loures. Para qualquer questão sobre esta política, escreva para geral@astrografe.pt ou ligue para 219 822 088.

2. Que dados recolhemos e porquê

Só recolhemos dados quando é você a enviá-los, através dos formulários de pedido de orçamento e de contacto.

  • Pedido de orçamento: nome, empresa, email, telefone, NIF, e os detalhes do pedido (família de produto, quantidade, formato, prazo, ligação para ficheiros e mensagem).
  • Contacto: nome, email, telefone e a mensagem que escrever.

Usamos estes dados apenas para responder ao seu pedido e, se avançarmos para uma encomenda, para tratar dela. O fundamento é a necessidade de dar seguimento ao seu pedido antes de um contrato e, depois, de o cumprir. Não usamos os dados para publicidade nem os vendemos a ninguém.

3. Com quem partilhamos

Os formulários são enviados através do serviço Web3Forms, que recebe os dados e os entrega por email à Astrografe. Este fornecedor trata os dados em nosso nome e apenas para esse fim.

Se carregar no mapa da página de contactos, o mapa é fornecido pela Google. Só é carregado depois de o pedir, e a Google passa a receber o seu endereço IP e dados do seu navegador. Veja a política de cookies.

4. Quanto tempo guardamos

Guardamos os dados durante o tempo necessário para tratar do seu pedido e, havendo encomenda, durante os prazos que a lei exige para documentos comerciais e fiscais. Depois disso, apagamo-los.

5. Os seus direitos

Pode pedir-nos a qualquer momento o acesso aos seus dados, a retificação do que esteja errado, o apagamento, a limitação do tratamento, a oposição e a portabilidade. Para exercer estes direitos, escreva para geral@astrografe.pt.

Se achar que tratamos os seus dados de forma indevida, tem direito a apresentar reclamação à Comissão Nacional de Proteção de Dados (cnpd.pt).

6. Segurança

Tomamos medidas técnicas e organizativas para proteger os dados contra perda, uso indevido ou acesso não autorizado. O acesso aos pedidos recebidos é limitado a quem precisa deles para responder.

7. Alterações

Podemos atualizar esta política. A versão em vigor é sempre a que está nesta página.
